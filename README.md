# 轻释压

轻释压是一个无需账号的本地压力记录与复盘 PWA。记录保存在当前浏览器的 IndexedDB 中，不会上传到服务器。

## 开始使用

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可使用。首次使用不需要注册或登录。

## 测试与构建

```bash
npm test -- --run
npm run test:e2e
npm run build
```

生产构建会生成 `dist/`，其中包含可离线使用的 PWA 资源。

## 数据与备份

所有记录仅保存在本机浏览器。清除浏览器站点数据、卸载应用或更换浏览器可能导致记录无法恢复。请在“设置”中使用“导出 JSON”或“导出 CSV”下载备份；导出文件也不会自动上传。
